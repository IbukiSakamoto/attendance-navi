# 出席ナビ

千葉工業大学の出席登録ページへ素早く移動するための、小規模な静的Webサイトです。**出席の自動登録は行いません。**

## 仕様

- 月〜金曜日の全10講義を曜日ごとに固定登録。土日は「本日の講義はありません」と表示します。
- **当日の講義のみ**一覧表示。各講義に時限、講義名、受付時間、受付状態（受付前・受付中・受付終了）を表示します。
- 出席リンクの表示は、最初の時限の**開始30分前から開始1時間後の直前まで**です。表示範囲外ではリンクを作成しません。
- 「受付中」のときだけボタンが表示され、クリックすると出席ページが**新しいタブ**で開きます。
- 表示は日本時間（`Asia/Tokyo`）で判定し、ページを開いたままでも毎分更新します。タブへの復帰時にも状態を更新します。
- 祝日・休講・補講などは考慮しません。大学側の受付時間や授業の実施状況を保証するものではありません。
- スマートフォンとタブレットで通常画面を表示し、PCでは利用案内を表示します。
- 検索結果に載りにくくするための `noindex` 指定があります。**アクセス制限ではありません**。
- ユーザーごとの登録、データベース、外部ライブラリ、認証は不要です。

## ファイル構成

- `index.html`：ページ本体と `noindex` 設定
- `styles.css`：スマートフォン・タブレット向けデザイン
- `app.js`：10講義の固定URL、曜日・受付時間判定、状態自動更新
- `.nojekyll`：GitHub Pagesで静的ファイルをそのまま公開するための空ファイル

## GitHub Pagesへの公開

1. GitHubで**公開（Public）**リポジトリを作成します（例：`attendance-navi`）。
2. `index.html`、`styles.css`、`app.js`、`.nojekyll` を**リポジトリのルート**にアップロードしてコミットします。`README.md` も同時に置けます。
3. リポジトリの **Settings → Pages → Build and deployment** で Source を **Deploy from a branch**、Branch を **main**、Folder を **/(root)** に設定し、Saveします。
4. 公開後、`https://<GitHubユーザー名>.github.io/attendance-navi/` の形式で表示されます。名前を変えた場合は読み替えてください。
5. スマートフォン・タブレットで、講義の受付時間帯にリンクが正しく出ることを確認してください。

公式案内：[GitHub Pagesの公開元の設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 設定の変更

講義データは `app.js` 冒頭の `courses` にまとまっています。

```javascript
{ day: 3, periods: '2・3限', name: '情報倫理', start: '10:00', room: '646' }
```

- `day`：月=1、火=2、水=3、木=4、金=5
- `periods`：時限の表示文字列
- `name`：講義名
- `start`：**最初の時限の開始時刻**（日本時間）
- `room`：URL末尾の数字。リンクは `https://attendance.is.chibatech.ac.jp/attendance/class_room/` + `room` で生成されます。

既存のデータでは同じ `room` 値を使う講義があります。これらもそれぞれ別の講義として扱います。

## 注意

- 本サイトは大学の公式サービスではありません。大学の学内ネットワーク利用・認証・出席登録の仕組みは回避しません。
- GitHub Pagesは原則公開サイトです。`noindex` とPC向け案内画面は認証・閲覧制限ではありません。公開ソースからURLを確認でき、ブラウザの端末情報も偽装可能です。
- 日時判定は閲覧端末の時計を元にします。時計の時刻を変更しても大学の出席受付を変更できるわけではありません。
- 一部の端末（例：Windowsタブレット）はPCと判定される場合があります。iPadのデスクトップ表示への対策は含めていますが、すべてのブラウザで完全に判定できるわけではありません。
- 外部からの実際の出席URLへのアクセスや大学側での登録完了までは検証していません。大学のルールに従って使用してください。
